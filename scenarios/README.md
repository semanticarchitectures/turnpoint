# scenarios/

Scenario definitions for agent evaluation: data sets, an objective and
notional threats, scored by `turnpoint.scenario` (decision 0013). Format
in `docs/specs/scenario-format.md`. All scenario content is notional and
uses public data only.

- `phase1-demo/`, `phase2-demo/`: walkthroughs of the Phase 1 and 2 exit
  criteria — a one-paragraph tasking driven over MCP/REST, not scenario
  files.
- `phase3-demo/`: a real scenario file (`docs/specs/scenario-format.md`)
  and two routes scored against it, for the Phase 3 exit criterion.
