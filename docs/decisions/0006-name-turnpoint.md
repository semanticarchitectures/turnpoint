# 0006. The project is named Turnpoint

- Status: accepted
- Date: 2026-09-21

## Context
"FalconView" is a registered trademark. "AMPS" is the U.S. Army's Aviation Mission Planning System. "OpenAMP" is a Linux Foundation project.

## Decision
The name is Turnpoint, tagline "open aircrew mission planning software". Package name `turnpoint` (unclaimed on PyPI as of this date).

## Consequences
A trademark search is still required before the first tagged release.
