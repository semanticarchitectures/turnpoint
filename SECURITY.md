# Security and data spills

This is a public repository. If you believe controlled, classified or
export-controlled information has been committed, opened in an issue, or attached
to a pull request:

1. Do **not** discuss the content publicly or quote it.
2. Email kevin.g.kelly@semanticarchitectures.com with the location only
   (commit hash, issue number, file path).
3. Do not try to clean it up yourself; history rewriting will be coordinated.

Report ordinary software vulnerabilities to the same address.
